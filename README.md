# Eventify – Event Management System

## Description

Eventify is a web-based event management system designed to simplify event planning and booking processes. It allows users to explore, book, and manage events while enabling vendors and administrators to efficiently handle event listings and customer interactions.

---

## Features

### User Features

* User registration and login
* Browse and search events
* Book events بسهولة
* View booking details

### Admin Features

* Admin dashboard
* Manage events and vendors
* Monitor bookings and users
* Update and delete event listings

### Vendor Features

* Vendor registration
* Add and manage event services
* Update event details and pricing

---

## Tech Stack

* Frontend: HTML, CSS, JavaScript, Bootstrap
* Backend: PHP
* Database: MySQL

## How to Run

1. Install XAMPP or any local server
2. Move project folder to htdocs
3. Start Apache and MySQL
4. Import database.sql into phpMyAdmin
5. Open browser and run: http://localhost/eventify
